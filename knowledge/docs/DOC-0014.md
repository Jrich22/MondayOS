# Cue App — Engineering Backlog

The live backlog lives as MondayOS tasks. This is the structural map:
10 epics, with the Sprint 1 foundation tasks called out. Query live state
with `monday task list`.

## Epics
- `TASK-0020` [P1] [EPIC] Event Workspace
    The core container for a single event and its state — the surface every other capability hangs off of.
- `TASK-0021` [P1] [EPIC] Guest / Attendee Management
    Represent, segment, and manage guests and attendees, portfolio-aware by design.
- `TASK-0022` [P1] [EPIC] AI Agenda Builder
    Generate a credible draft agenda for an event from a short brief — the AI-native planning wedge.
- `TASK-0023` [P1] [EPIC] Invite & RSVP Flow
    Invite guests and capture RSVP status in-app, without external email/CRM integrations.
- `TASK-0024` [P2] [EPIC] Vendor / Venue Tracker
    Track vendors and the venue for an event with status and a basic checklist.
- `TASK-0025` [P2] [EPIC] Run-of-Show Builder
    Build an ordered day-of timeline that drives event execution.
- `TASK-0026` [P1] [EPIC] Portfolio-Company Tagging
    Tag guests and companies to the firm's portfolio and network — the intelligence foundation.
- `TASK-0027` [P2] [EPIC] Post-Event Recap & Insights
    Produce a structured recap and insights after an event to close the learning loop.
- `TASK-0028` [P2] [EPIC] Admin Dashboard
    The firm-level surface: event portfolio at a glance, settings, and seed/demo control.
- `TASK-0029` [P1] [EPIC] AI Assistant Layer
    The pervasive AI assistant surface that will drive planning and execution across Cue.

## Sprint 1 tasks (MVP foundation)
- `TASK-0030` [P1] Build the app shell (navigation + layout)  (epic: [EPIC] Event Workspace)
- `TASK-0031` [P1] Auth placeholder (no production auth)  (epic: [EPIC] Admin Dashboard)
- `TASK-0032` [P1] Event dashboard (list of events)  (epic: [EPIC] Event Workspace)  ⟵ depends on TASK-0030
- `TASK-0033` [P1] Create-event flow  (epic: [EPIC] Event Workspace)  ⟵ depends on TASK-0030
- `TASK-0034` [P1] Basic event detail page  (epic: [EPIC] Event Workspace)  ⟵ depends on TASK-0033
- `TASK-0035` [P1] Guest list model  (epic: [EPIC] Guest / Attendee Management)  ⟵ depends on TASK-0034
- `TASK-0036` [P2] AI assistant placeholder  (epic: [EPIC] AI Assistant Layer)  ⟵ depends on TASK-0030
- `TASK-0037` [P2] Seed demo data  (epic: [EPIC] Admin Dashboard)  ⟵ depends on TASK-0032, TASK-0035

Epics beyond Sprint 1 are sequenced in the V1 Roadmap knowledge entry.
