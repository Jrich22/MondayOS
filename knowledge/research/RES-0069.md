# Cue App: Multi-Organization Architecture Design

## Executive Summary

This document defines the complete multi-organization architecture for Cue App, enabling support for diverse organization types (Venture Capital, Private Equity, Conferences, Corporate Events, Executive Offsites, Customer Advisory Boards, University Alumni, Nonprofits, and Associations) through a flexible, composable data model with industry profiles, configurable fields, feature flags, and a permissions system designed to scale to full multi-tenancy.

---

## 1. Core Architecture Overview

```
┌─────────────────────────────────────────────────────────────────┐
│                        CUE APP PLATFORM                         │
├─────────────────────────────────────────────────────────────────┤
│  Tenant Layer        │  Organization Layer  │  Workspace Layer  │
│  ──────────────      │  ──────────────────  │  ──────────────   │
│  TenantAccount       │  Organization        │  Workspace        │
│  (future billing     │  (the "company" or   │  (a team/project  │
│   + isolation unit)  │   community entity)  │   space within)   │
├─────────────────────────────────────────────────────────────────┤
│  Industry Profile    │  Feature Flags       │  Permission Roles  │
│  (behavioral presets │  (capability on/off  │  (RBAC + scoped    │
│   per org type)      │   per org/workspace) │   permissions)     │
└─────────────────────────────────────────────────────────────────┘
```

### Design Principles

1. **Composability over inheritance** — Org types are *profiles*, not rigid subclasses
2. **Progressive disclosure** — Features unlock as orgs need them, not forced upfront
3. **Tenant isolation by default** — All data scoped to tenant from day one
4. **Explicit over implicit** — Permissions and capabilities are declared, never assumed
5. **Schema-first** — Configurable fields are typed and validated, not arbitrary blobs

## 2. Organization Model

### 2.1 Core Organization Schema

```typescript
// types/organization.ts

export type OrgType =
  | 'venture_capital'
  | 'private_equity'
  | 'conference'
  | 'corporate_events'
  | 'executive_offsite'
  | 'customer_advisory_board'
  | 'university_alumni'
  | 'nonprofit'
  | 'association'
  | 'custom';  // escape hatch for unlisted types

export type OrgSize = 'solo' | 'small' | 'medium' | 'large' | 'enterprise';
// solo: 1, small: 2–25, medium: 26–200, large: 201–2000, enterprise: 2000+

export type OrgStatus = 'active' | 'suspended' | 'archived' | 'onboarding';

export interface Organization {
  // --- Identity ---
  id: string;                        // UUID v4, immutable
  slug: string;                      // URL-safe, unique, changeable with redirect
  displayName: string;               // "Sequoia Capital"
  legalName?: string;                // "Sequoia Capital Operations, LLC"
  logoUrl?: string;
  brandColor?: string;               // hex, used for white-label theming

  // --- Classification ---
  orgType: OrgType;
  orgSize: OrgSize;
  industryProfileId: string;         // FK → IndustryProfile
  customFields: CustomFieldValue[];  // instantiated from profile's field defs

  // --- Configuration ---
  featureFlags: OrgFeatureFlags;     // org-level overrides
  settings: OrgSettings;
  
  // --- Tenant binding ---
  tenantId: string;                  // FK → TenantAccount (may equal org.id in MVP)
  
  // --- Relationships ---
  workspaceIds: string[];            // FK[] → Workspace
  ownerUserId: string;               // FK → User (billing/legal owner)
  
  // --- Lifecycle ---
  status: OrgStatus;
  createdAt: ISO8601DateTime;
  updatedAt: ISO8601DateTime;
  archivedAt?: ISO8601DateTime;

  // --- Audit ---
  createdByUserId: string;
  lastModifiedByUserId: string;
}

export interface OrgSettings {
  timezone: string;                  // IANA tz, e.g. "America/New_York"
  locale: string;                    // BCP 47, e.g. "en-US"
  dateFormat: 'MM/DD/YYYY' | 'DD/MM/YYYY' | 'YYYY-MM-DD';
  allowGuestAccess: boolean;
  requireMFA: boolean;
  ssoEnabled: boolean;
  ssoProviderConfig?: SSOProviderConfig;
  allowedEmailDomains: string[];     // [] means no restriction
  maxWorkspaces: number | null;      // null = unlimited
  maxMembersPerWorkspace: number | null;
  dataRetentionDays: number | null;  // null = indefinite
}
```

## 3. Workspace Model

Workspaces are the primary collaboration unit within an organization. An org can have multiple workspaces serving different purposes (e.g., a VC firm might have one workspace per portfolio company relationship, or per fund).

```typescript
// types/workspace.ts

export type WorkspacePurpose =
  | 'portfolio_management'    // VC/PE
  | 'deal_flow'               // VC/PE
  | 'event_planning'          // Conferences, Corporate Events
  | 'event_execution'         // live event ops
  | 'advisory_board'          // CAB
  | 'alumni_community'        // University Alumni
  | 'fund_management'         // PE
  | 'program_management'      // Nonprofits, Associations
  | 'committee'               // Associations
  | 'general';                // catch-all

export type WorkspaceVisibility = 'private' | 'org_internal' | 'public';

export interface Workspace {
  // --- Identity ---
  id: string;
  organizationId: string;            // parent org
  name: string;
  description?: string;
  purpose: WorkspacePurpose;
  iconEmoji?: string;
  coverImageUrl?: string;

  // --- Configuration ---
  visibility: WorkspaceVisibility;
  featureFlags: WorkspaceFeatureFlags; // workspace-level overrides (subset of org)
  customFields: CustomFieldValue[];

  // --- Content ---
  moduleIds: string[];               // ordered list of enabled modules

  archivedAt?: ISO8601DateTime;
  createdAt: ISO8601DateTime;
  updatedAt: ISO8601DateTime;

}
