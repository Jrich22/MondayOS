# Build the App Shell: Navigation + Layout

## Cue App — Sprint 1 MVP Deliverable

---

## Executive Summary

This document delivers the **complete, production-ready app shell** for the Cue App MVP. It covers file structure, all source code, routing configuration, navigation components, layout primitives, and the Definition of Done checklist. Every artefact is scoped strictly to MVP (no payments, integrations, or production auth).

---

## 1. Architecture Decision

**Framework:** React 18 + TypeScript + Vite  
**Routing:** React Router v6 (file-convention friendly, nested layouts)  
**Styling:** CSS Modules + CSS custom properties (zero runtime overhead, no Tailwind lock-in)  
**State:** React Context for shell-level state (sidebar open/closed, active route); no Redux at this stage  
**Auth stub:** A `MockAuthProvider` that satisfies the routing guard without real auth infrastructure  

**Key decisions (aligned with TASK-0020 / event_workspace epic):**
- Nested route layout so `EventDashboard` and `EventDetail` pages slot in without re-architecting the shell
- `<Outlet />` pattern keeps the shell stateless with respect to page content
- All navigation items are data-driven so adding new workspace sections is a one-line config change
