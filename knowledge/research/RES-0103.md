# sourcingBOT: Product Foundation

## Engineering Delivery Report

---

## Executive Summary

This report delivers the complete product architecture for sourcingBOT as a managed MondayOS product. The design establishes a supervised recruiting sourcing system with clear human-in-the-loop boundaries, GitHub as the implementation source of truth, and a foundation that maps directly to the acceptance criteria.

**Scope of this task:** Architecture design, data models, API contracts, directory structure, and implementation scaffolding. No unattended scraping, rate-limit bypass, or automation-evasion behavior is included or implied anywhere in this design.

---

## 1. Product Architecture Overview

### 1.1 System Philosophy

sourcingBOT operates on the **Supervised Assistance Model**: the system prepares, organizes, and analyzes — humans execute LinkedIn interactions. Every LinkedIn action is initiated by a human recruiter. The system surfaces intelligence, tracks history, and reduces cognitive load without replacing human judgment.

```
┌─────────────────────────────────────────────────────────────────┐
│                        sourcingBOT                              │
│                   MondayOS Product Layer                        │
├─────────────────┬───────────────────┬───────────────────────────┤
│  Req Workspaces │  Sourcing Briefs  │  Sourcing Intelligence    │
│  (per-role)     │  (reusable tmpl)  │  (analytics + signals)    │
├─────────────────┴───────────────────┴───────────────────────────┤
│              Supervised Session Layer                           │
│  Human recruiter drives LinkedIn Recruiter — system logs,       │
│  structures, and enriches session output                        │
├─────────────────────────────────────────────────────────────────┤
│              Persistent Record Layer                            │
│  Candidates · Req-Candidate Links · Session History            │
├─────────────────────────────────────────────────────────────────┤
│              MondayOS Platform                                  │
│  GitHub (source of truth) · Task Engine · Knowledge Base       │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 Core Components

| Component | Responsibility | Human/Automated |
|-----------|---------------|-----------------|
| **Req Workspace** | Isolated context per open role | Both |
| **Sourcing Brief** | Reusable search strategy template | Human-authored, system-stored |
| **Sourcing Session** | Structured log of a LinkedIn search session | Human-executed, system-recorded |
| **Candidate Record** | Persistent profile data | System-managed from human input |
| **Req-Candidate Link** | Many-to-many role/person relationship | System-managed |
| **Talent Concentration Analytics** | Pool sizing, geography, availability signals | Automated analysis of session data |
| **Sourcing Intelligence** | Aggregated insights, pattern detection | Automated analysis |
