## Architecture Decisions

Before writing code, I'll establish the key decisions:

1. **No real auth** — use a mock current-user context (MVP scope)
2. **No payments/integrations** — pure UI + local state/mock data
3. **Component-driven** — composable, testable units
4. **Status-at-a-glance** — visual status chips, counts, and date proximity indicators
