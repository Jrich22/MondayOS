### Core Design Principles

| Principle | Implementation |
|-----------|---------------|
| Human Oversight | Every LinkedIn interaction requires explicit human approval before execution |
| No Automation Evasion | System never simulates human timing, rotates IPs, or bypasses rate limits |
| GitHub as Source of Truth | All specs, schemas, and decisions live in `/docs` and are PR-reviewed |
| Supervised Sessions | Sessions are queued, reviewed, and manually triggered — never autonomous |
| Audit Trails | Every candidate touch, session action, and recommendation is logged with actor identity |
