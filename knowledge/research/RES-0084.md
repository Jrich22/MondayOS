## 1. Architecture Overview

### 1.1 Design Philosophy

The dashboard is architected as a **three-tier progressive disclosure system**:

```
Tier 1: Single Event View      → Organizer managing one active event
Tier 2: Organization View      → Organization managing multiple events
Tier 3: Portfolio View         → Enterprise/agency managing multiple orgs
```

This aligns with the CPO's roadmap requirement to "evolve from single-event into organization-wide and portfolio-wide views" without requiring architectural rewrites at each stage.
