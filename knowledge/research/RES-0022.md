## 1. Shared Type: `src/types/event.ts`

> **Note:** TASK-0033 is a dependency. If this type already exists, use it verbatim. This definition is the canonical MVP shape.

```typescript
// src/types/event.ts

export type EventStatus = 'draft' | 'confirmed' | 'cancelled';

export interface CueEvent {
  id: string;
  title: string;
  description: string | null;
  date: string;          // ISO 8601 — e.g. "2025-09-14T19:00:00Z"
  location: string | null;
  status: EventStatus;
  guestCount: number;    // denormalised count; guests live in their own workspace
  createdAt: string;     // ISO 8601
  updatedAt: string;     // ISO 8601
}
```

**Why this shape:**
- `date` and timestamps as ISO strings — safe across serialisation boundaries (Server → Client Components)
- `guestCount` is a cheap denormalised field; full guest list lives in the guests workspace (TASK-0033 boundary)
- No payment, integration, or auth fields — MVP scope enforced at the type level
