To build the app shell (navigation + layout) for the Cue App while adhering to the acceptance criteria, follow these actionable steps:

### Actionable Steps:

1. **Set Up Project Structure**  
   - Create a new directory structure for your app shell if it is not already set up, ensuring it follows best practices for organization within the `cue-app` component of your repository.
   - Suggested structure:
     ```
     cue-app/
       ├── components/
       │   ├── Navbar/
       │   ├── Sidebar/
       │   ├── Footer/
       ├── layouts/
       │   ├── MainLayout/
       ├── pages/
       ├── routes/
       ├── App.js
       └── index.js
     ```

2. **Install Required Dependencies**  
   - If you are using a framework like React, make sure to include necessary packages for routing, like `react-router-dom`.
   ```bash
   npm install react-router-dom
   ```

3. **Create Basic Layout Components**  
   - **Navbar**: Create a `Navbar` component that includes links to the event dashboard and detail pages.
   - **Sidebar**: (Optional) Create a `Sidebar` component for any additional navigation options or quick links if required for the MVP.
   - **Footer**: Create a `Footer` component with basic copyright information.
   
   Example `Navbar.js`:
   ```jsx
   import React from 'react';
   import { Link } from 'react-router-dom';

   const Navbar = () => (
     <nav>
       <ul>
         <li><Link to="/">Dashboard</Link></li>
         <li><Link to="/event-detail">Event Detail</Link></li>
       </ul>
     </nav>
   );

   export default Navbar;
   ```

4. **Create Main Layout**  
   - Define a `MainLayout` component that uses the `Navbar`, `Sidebar`, and `Footer`, serving as the primary layout for all your pages.
   
   Example `MainLayout.js`:
   ```jsx
   import React from 'react';
   import Navbar from '../components/Navbar';
   import Sidebar from '../components/Sidebar';
   import Footer from '../components/Footer';

   const MainLayout = ({ children }) => (
     <div>
       <Navbar />
       <div className="content">
         <Sidebar />
         <main>{children}</main>
       </div>
       <Footer />
     </div>
   );

   export default MainLayout;
   ```

5. **Set Up Routing**  
   - In `App.js`, set up the routing using `react-router-dom` to navigate between the dashboard and event detail pages.
   
   Example `App.js`:
   ```jsx
   import React from 'react';
   import { BrowserRouter as Router, Route, Switch } from 'react-router-dom';
   import MainLayout from './layouts/MainLayout';
   import Dashboard from './pages/Dashboard';
   import EventDetail from './pages/EventDetail';

   const App = () => (
     <Router>
       <MainLayout>
         <Switch>
           <Route exact path="/" component={Dashboard} />
           <Route path="/event-detail" component={EventDetail} />
         </Switch>
       </MainLayout>
     </Router>
   );

   export default App;
   ```
