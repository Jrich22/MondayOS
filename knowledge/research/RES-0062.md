# Cue App: Multi-Organization Architecture Design

## Executive Summary

This document defines the complete multi-organization architecture for the Cue App, enabling a single platform to serve Venture Capital firms, Private Equity funds, Conferences, Corporate Events, Executive Offsites, Customer Advisory Boards, University Alumni networks, Nonprofits, and Associations. The design prioritizes configurability over code branching, using a profile-driven system that adapts terminology, fields, features, and permissions to each organization type.

---

## 1. Organization Model

### 1.1 Core Organization Entity

```typescript
// types/organization.ts

export type OrganizationTypeSlug =
  | 'venture_capital'

export interface Organization {
  id: string;                          // UUID v4

  legalName?: string;                  // Legal entity name if different

  industryProfileId: string;           // FK → IndustryProfile

  logoUrl?: string;
  brandColor?: string;                 // Hex for white-labeling
  domain?: string;                     // Primary email domain e.g. "sequoia.com"
  allowedDomains: string[];            // Domains permitted to join via SSO
  region: string;                      // 'us' | 'eu' | 'apac' etc. (for data residency)
  timezone: string;                    // IANA timezone
  createdAt: Date;
  updatedAt: Date;
  metadata: Record<string, unknown>;   // Escape hatch for org-specific config
}

export type OrgTier = 'free' | 'starter' | 'growth' | 'enterprise';
export type OrgStatus = 'active' | 'suspended' | 'archived' | 'onboarding';
```

## 2. Workspace Model

Workspaces are sub-units within an organization. A VC firm might have workspaces per fund vintage; a Conference might have one workspace per event edition.

### 2.1 Workspace Entity

```typescript
// types/workspace.ts

export interface Workspace {
  id: string;
  organizationId: string;             // Parent org
  name: string;                       // "Fund III" or "Summit 2025"
  slug: string;                       // URL segment
  description?: string;
  workspaceType: WorkspaceType;
  status: 'active' | 'archived' | 'draft';
  visibility: 'private' | 'org_members' | 'public';
  
  // Temporal scoping (critical for event-type orgs)
  startDate?: Date;
  endDate?: Date;
  
  // Ownership
  ownerId: string;                    // User who created/owns the workspace
  adminIds: string[];                 // Additional admins
  
  // Configuration inheritance
  inheritOrgSettings: boolean;        // If false, workspace overrides are respected
  settingsOverride?: Partial<WorkspaceSettings>;
  
  // Custom fields defined for this workspace (subset of org-level fields)
  enabledCustomFieldIds: string[];
  
  // Feature flag overrides (workspace can downgrade but not upgrade beyond org tier)
  featureFlagOverrides: Partial<FeatureFlags>;
  
  createdAt: Date;
  updatedAt: Date;
}

export type WorkspaceType =
  | 'fund'                 // VC/PE fund vintage
  | 'portfolio'            // PE portfolio company grouping
  | 'event_edition'        // Conference or event occurrence
  | 'cohort'               // Alumni class year
  | 'program'              // Nonprofit program
  | 'chapter'              // Association chapter
  | 'committee'            // CAB committee
  | 'general';             // Generic fallback
```
