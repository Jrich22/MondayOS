Cue App is built as a client-side SPA on React 18 + Vite + TypeScript + Tailwind CSS (dark-first premium design system). No tech stack was pinned in the product docs, so this was chosen at the start of Sprint 1 (TASK-0032, Event Dashboard) and is the foundation every Sprint 1 surface hangs off. Rationale: fastest path to a premium, modern UI for a mock-data MVP; no backend needed yet. Routing is react-router-dom via HashRouter to keep the SPA self-contained with no server route config. Design tokens live in tailwind.config.ts. Component: cue-app.
