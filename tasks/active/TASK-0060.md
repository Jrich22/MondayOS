- '`sourcingbot-host` is a single local process that is the ONLY writer of
  `~/.sourcingbot/workspace.json`. A test asserts a second host instance refuses to start
  rather than racing the first.'
- 'The host reuses the existing domain functions (`captureCandidate`, `commitCapture`,
  `recordSkip`, `pauseSession`, `completeSession`) verbatim. No write path bypasses them.
  A test asserts a host-side capture and a UI-side capture produce identical records.'
- 'HTTP API on 127.0.0.1 only — never `0.0.0.0`, asserted by a test on the bind address.
  No authentication is claimed or implied; the loopback bind is the boundary.'
- 'Server-Sent Events stream workspace changes to the SPA. A test asserts a host-side
  mutation reaches a subscribed client without polling.'
- '`store.ts` changes only in `load()` and `persist()`; the `useSyncExternalStore` seam and
  every exported store function keep their signatures. No component or page imports storage
  or `fetch` directly.'
- 'Document-level optimistic concurrency: the workspace carries a monotonic `version`; a
  write against a stale version is REJECTED, never merged. Tested with a concurrent-write case.'
- 'Host unavailable degrades explicitly: the SPA falls back to `localStorage` and
  `ManualProvider`, and renders a visible local-only indicator. A test asserts the indicator
  appears and that the fallback is never silent.'
- 'Manual sourcing works end to end against the host with no Claude and no MCP involvement:
  create req, author brief, start session, capture, skip, complete.'
- 'The workspace file is written atomically (temp file + rename) so an interrupted write
  cannot truncate it. Tested against a simulated mid-write failure.'
- 'A corrupt or unreadable workspace file does not silently reset to seed data: the host
  refuses to start and reports the file path, so real work is never destroyed by a parse error.'
- 'Startup, port selection, and shutdown are documented in `projects/sourcingbot/README.md`,
  including what happens when the port is taken.'
- 'No MCP server, no provider beyond Manual, and no browser control ship in this increment.'
- 'Full validation green: sourcingBOT `vitest` (including new host tests), TypeScript strict,
  production build, MondayOS `pytest`, and Cue App tests with zero Cue changes.'
